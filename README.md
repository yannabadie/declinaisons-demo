# Une maquette, dix formats — démonstration

Vidéo de démonstration (35 s, muette) d'un outil de déclinaisons de supports graphiques : une maquette maîtresse
déclinée en dix formats imprimés et numériques. Pour chaque format, le rapport de l'outil dit ce qu'il a ajusté et ce
qu'il signale ; chaque format est ensuite contrôlé avant livraison.
